# UNICEF 3D Print Shop

Website to showcase and sell 3D-printed items with proceeds pledged to support donation efforts aligned with UNICEF values.

## Setup

```bash
cd unicef-3d-print-shop
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- React Router

## Disclaimer

Independent demo. For official UNICEF donations use [unicef.org](https://www.unicef.org). Secure permissions before using UNICEF branding.

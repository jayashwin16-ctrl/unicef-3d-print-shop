# 3D printable files (STL)

Place one `.stl` file per product here. File names must match `modelFile` in `src/data/products.ts`.

| File | Product |
|------|---------|
| `egg-fidget.stl` | Egg fidget |
| `samurai-sword.stl` | Samurai sword |
| `articulated-dragon.stl` | Articulated dragon |
| `shiny-dragon.stl` | Shiny dragon |
| `skull-pass-through.stl` | Skull pass-through |

After adding files, commit and push so Vercel serves them at `/downloads/…`.
